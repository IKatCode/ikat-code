# IKat Code

Агент для программирования в терминале. Вы говорите, что нужно сделать, IKat читает проект,
правит код, запускает ваши тесты и рассказывает, что изменил.

Он не привязан к одному поставщику. Подойдёт любой сервер с API в формате OpenAI: сама OpenAI,
OpenRouter, модель на вашем компьютере (Ollama, LM Studio, llama.cpp, vLLM) или шлюз вашей
компании. Работают и ключи Anthropic и Google, и вход через подписку ChatGPT.

![IKat исправляет ошибку: меняет одну строку, добавляет тест и запускает тесты проекта](docs/fix-bug.svg)

## Установка

macOS и Linux:

```sh
curl -fsSL https://github.com/IKatCode/ikat-code/releases/latest/download/install.sh | sh
```

Windows, в PowerShell:

```powershell
irm https://github.com/IKatCode/ikat-code/releases/latest/download/install.ps1 | iex
```

Установщик сверяет загрузку с подписанными контрольными суммами релиза, кладёт `ikat` в
`~/.ikat/bin` (на Windows в `%LOCALAPPDATA%\ikat\bin`) и добавляет эту папку в PATH. После
установки откройте новый терминал.

Сборки есть для macOS (Intel, Apple Silicon), Linux (x64, arm64; glibc и musl) и Windows (x64,
arm64).

- Windows: команды IKat выполняет в Git Bash, нужен [Git for Windows](https://git-scm.com/download/win).
  Подпись проверяется через `ssh-keygen`, он в Windows 10 и 11 уже есть.
- Alpine и другие системы на musl: сначала `apk add libstdc++ libgcc`.

## Подключение модели

Запустите `ikat` в папке проекта. В первый раз он спросит, как подключаться к модели, и запомнит
ответ. Можно настроить и вручную.

Любой OpenAI-совместимый сервер описывается в `~/.ikat/settings.json`:

```json
{
  "providers": {
    "corp": {
      "baseUrl": "https://llm.corp.example/v1",
      "apiKeyEnv": "CORP_LLM_KEY",
      "models": { "coder-xl": { "contextWindow": 200000 } }
    }
  }
}
```

```sh
ikat --model corp/coder-xl
```

Ключ берётся из переменной, названной в `apiKeyEnv`, или из `ikat login corp` — тогда он хранится
в системном хранилище ключей. Настройки самого проекта (`.ikat/settings.json`) провайдеров не
добавляют и не меняют: склонированный репозиторий не решает, куда уходит ваш код.

Локальный сервер находится сам:

```sh
ikat --model ollama/qwen3-coder:30b
ikat --model lmstudio/<модель>     # а также llamacpp/<модель>, vllm/<модель>
```

Модель должна уметь вызывать инструменты. Если сервер не сообщает размер контекста, IKat считает
его равным 32 768 токенам; если у вас другой, укажите `contextWindow`.

Ключи крупных провайдеров: `ikat login openai`, `ikat login anthropic`, `ikat login google`,
`ikat login openrouter` или обычные переменные (`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`,
`GEMINI_API_KEY`, `OPENROUTER_API_KEY`). Подписка ChatGPT Plus или Pro: `ikat login` и вход в
браузере.

`ikat doctor` показывает, что из этого настроено. `/model` меняет модель посреди разговора.

## Работа

```sh
cd ваш/проект
ikat
```

И опишите задачу своими словами, например:

```
Итог корзины не учитывает скидки на наборы. Разберись почему и исправь.
```

| | |
|---|---|
| `Esc` | остановить текущий шаг |
| `Esc Esc` или `/rewind` | откатить файлы и разговор к одной из прошлых точек |
| `ikat -c` / `ikat -r` | продолжить последний разговор в этой папке / выбрать более старый |
| `/init` | записать `IKAT.md`: как собрать и протестировать проект; IKat читает его в каждой сессии |
| `/` и `?` | все команды и все клавиши |

## Права

Перед командой или изменением файла IKat показывает, что собирается сделать и насколько это
рискованно. Можно разрешить один раз, разрешить такие команды в этом проекте насовсем или
отказать и сказать, что делать вместо этого.

![IKat спрашивает, можно ли выполнить git status: уровень риска и три варианта ответа](docs/ask.svg)

Режимы определяют, о чём он спрашивает. `Shift+Tab` переключает первые три; любой можно задать
через `/mode <имя>` или `ikat --permission-mode <имя>`.

| Режим | Что делает |
|---|---|
| `default` | спрашивает о командах и изменениях файлов |
| `accept-edits` | меняет файлы проекта без вопросов, о командах спрашивает |
| `plan` | составляет план и ждёт вашего «да», прежде чем что-то менять |
| `auto` | как `accept-edits`, и ещё без вопросов выполняет команды, которые не выходят из песочницы (macOS и Linux) |
| `readonly` | только читает: ничего не пишет и не запускает |

### Совсем без вопросов

`bypass-permissions` не спрашивает ничего, на любой системе, в том числе на Windows. Запустить
сессию в этом режиме:

```sh
ikat --permission-mode bypass-permissions
```

или переключить открытую сессию: `/mode bypass-permissions`. Чтобы режим был по умолчанию, добавьте
в `~/.ikat/settings.json`:

```json
{ "permissions": { "defaultMode": "bypass-permissions" } }
```

`Shift+Tab` в этот режим не переключает, а настройки проекта не могут его включить. Ваши
запрещающие правила и защита секретов (файлы `.env`, `~/.ssh`, ключи облаков) продолжают
действовать, всё остальное выполняется. На macOS и Linux команды по-прежнему запускаются в
песочнице, но если команде нужно из неё выйти, её выпустят без вопроса. На Windows песочницы нет,
и команда может всё, что можете вы. Включайте этот режим в контейнере, в виртуальной машине или в
копии проекта, которую не жалко.

## Скрипты и CI

```sh
ikat -p "Почини падающий тест в cart.test.ts" --permission-mode accept-edits --allowed-tools "Bash(npm test:*)"
```

`-p` выполняет одну задачу без интерфейса. Спросить он не может, поэтому всё, что требует
вопроса, отклоняется, и IKat печатает правило, которое это разрешило бы. Каждому правилу — свой
`--allowed-tools`. `--output-format json` или `stream-json` дают результат, который удобно читать
другой программе. В одноразовом контейнере CI `--permission-mode bypass-permissions` разрешает всё.

## Песочница

На macOS и Linux команды, которые запускает IKat, могут писать только в папку проекта и во
временную папку, а сети у них нет, если вы не открыли её в настройках для нужных адресов. Что-то
вроде `npm install` сначала спросит разрешения и выполнится вне песочницы. На Windows песочницы
пока нет; если она нужна, запускайте IKat в WSL.

Настройки проекта, например команды, которые он разрешает без вопросов, начинают действовать
только после того, как вы подтвердите доверие к папке. Перед этим IKat показывает, что в них.

## Обновление и удаление

Чтобы обновиться, запустите команду установки ещё раз.

Чтобы удалить IKat, удалите папку, которую создал установщик (`~/.ikat/bin` или
`%LOCALAPPDATA%\ikat\bin` на Windows), и уберите её из PATH. Сессии и настройки лежат в `~/.ikat`.

## Если что-то не работает

Запустите `ikat doctor`: он проверит терминал, Git, подключение к модели и настройки. Если не
помогло, [создайте issue](https://github.com/IKatCode/ikat-code/issues) и приложите его вывод.
О проблеме безопасности сообщайте не публично, а как описано в [SECURITY.md](SECURITY.md).

Интерфейс есть на русском и английском, язык берётся из настроек системы.

## Приватность

Код и запросы уходят только выбранному вами провайдеру модели. Телеметрии в IKat нет.
